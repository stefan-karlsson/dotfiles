# Enroll a channel the way its vendor does, and name the packages it shares

A repository is enrolled the way its vendor's own package enrolls it, and the packages more than one enrolled channel carries are declared as such. Two things on a company laptop made that explicit, and both are settled in the repository data rather than by hand.

A vendor whose package rewrites its own apt source at every install and upgrade wins over anything this source state writes to the same file. Microsoft Edge does exactly that: its `postinst` recreates `/etc/apt/sources.list.d/microsoft-edge.sources` with `packages.microsoft.com/repos/edge-stable` and its own keyring, so a channel declared any other way survives only until the next Edge release and is then read as a foreign repository. The declared channel therefore matches what that script writes, including the keyring path — the same Microsoft release-signing key the rest of this setup pins, in a second file — and a repeated field in the stanza the script generates is read as the single field apt reads it as.

A general-purpose vendor channel added for one application may also carry a package another channel owns. `packages.microsoft.com/ubuntu/26.04/prod`, enrolled for the Intune Portal, also carries `kubectl`, with a version string that outranks the Kubernetes channel's, so apt takes Microsoft's build on a company laptop and the Kubernetes project's build everywhere else. Such a package is declared as shared rather than held to one channel: both channels are enrolled here and each has its key pinned, the builds are of the same upstream Kubernetes release, and an apt preference that forced one of them would make every apply fight apt over packaging alone — the return would even be a downgrade in apt's terms, which apt refuses inside a batch install, for no difference in the `kubectl` that ends up on the laptop. What the preflight then asks of a shared package is that its installed version come from some channel this source state enrolled, rather than from the one repository that names it.
